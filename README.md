## 📌 About The Project

Counter Program is a simple interactive JavaScript application that allows users to increase or decrease a numerical value using buttons. The counter starts at zero, and the displayed number updates instantly whenever the user clicks the Increase or Decrease button.

## ✨ Features

- Start the counter at zero.
- Increase the counter value by clicking the Increase button.
- Decrease the counter value by clicking the Decrease button.
- Update the displayed number instantly.
- Simple and user-friendly interface.
- Interactive buttons with click events.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Click the Increase button to increase the counter.
5. Click the Decrease button to decrease the counter.
